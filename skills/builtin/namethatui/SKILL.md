# 给交互准确命名

先描述触发方式、所在位置、能否在面板外操作、焦点去向与关闭方式。靠近按钮展开、允许继续看页面的编辑表单通常是 popover；必须完成选择才继续的是 modal dialog。

区分 menu 的命令列表、listbox 的可选值、combobox 的可编辑查询、tooltip 的短提示。根据用户要执行的动作决定控件。

在规格中同时写可见中文和通用组件名，给出键盘进入、返回和读屏名称，交付时核对实现的实际行为。
