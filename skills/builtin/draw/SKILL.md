## Paint on a canvas

Use the authorized computer and its drawing application. Observe the document, locate the canvas edges, active brush, size, and foreground color. For a new picture, choose the document dimensions and save location. In an existing picture first identify what the user wants to preserve.

Block in the large light and dark masses. Choose the horizon and vanishing point for a perspective scene, or the main silhouettes for a portrait or still life. Work from background to subject to fine details. Make distant shapes lighter and softer. Reuse a small palette, reserving the strongest accent and sharpest edges for the subject.

Place points in screenshot pixels inside the observed canvas. Use the computer's `stroke` action with `strokes` containing paths of `[x, y]` points. Each path holds the primary button from its first point through the last, then lifts the brush. Use two points for a straight line and a few intermediate points around curves. Group independent paths of one color and width in a single action. Change the brush or palette by operating the actual toolbar. Observe again after panning, zooming, or moving the window before placing another mark.

Inspect the canvas after the first mark and each major pass. Check the footprint, edges, overlap, and gaps. Undo an incorrect stroke or batch according to the application's actual undo behavior. Work on details at the needed zoom, then return to the full composition. Save or export through the application and inspect the saved image at its intended size. Return the actual file the application saved.

## Editable diagrams in LibreOffice Draw

Use the visible shape tool to draw one box inside the page. Select its filled area and press F2 to edit its label. Confirm text-edit focus before replacing a label. Escape returns to the shape. Use the selection arrow when moving between objects.

For equal shapes, set the first shape’s size, then use Shift+F3 to duplicate it with the desired count and displacement. F4 exposes position and size in the displayed page unit. Fit the last copy within the page. Use Shape → Insert → Lines and Arrows → Line Ends with Arrow and drag from source to destination. Inspect arrowheads, labels and crossings, save the editable ODG, and export the requested image or PDF.

In the toolbars of LibreOffice Draw, pressing Escape can leave Text Box active. If a click inserts a separate text frame, undo it, choose the selection arrow, and click the original shape’s filled area. To enter a precise dimension, focus its numeric field, read the unit and replace the value in one text operation. Check the displayed value before applying it. Reuse an existing connector when its direction and endpoints match. After export, open the actual saved file from the device or work files.
