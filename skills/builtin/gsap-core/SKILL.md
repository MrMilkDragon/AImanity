# 补间与实时状态

为动画确定唯一的目标元素和最终值。用户反向操作时更新已有补间或从当前可见值继续，避免多个 tween 同时写同一属性。

把位置和透明度作为表现层，业务状态立即确定。使用项目已有的缓动与时长，释放组件时清理动画。

配套资料按需用 `skill_read` 的 `resource` 参数读取：
