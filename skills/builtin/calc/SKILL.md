Use computer-use with the observed application_id `linux:libreoffice-calc`. Work in the requested workbook or a separate copy when the original must be preserved. On a correction, update the same working copy and keep the other requirements.

Select the intended cell before typing. When the request changes or preserves a formula, select the formula cell before the final save so its expression and calculated value are visible. Verify the requested values and totals. Use Ctrl+S to save the workbook. When attaching it to this chat, set reply_file on that final computer_key to the observed document_path or the confirmed Save As path. For an already saved workbook use task_finish.files. Locate an unknown path with device_file_list. For another device or conversation, follow the transfer and delivery steps in computer-use.

For new sheets, multi-cell pastes, CSV import or a change of format, read [Import and Save As](references/import-and-save.md) using skill_read with name=calc and resource=references/import-and-save.md.
