# 按交互选择插件

确认项目安装版本与需要的能力。折叠后重新排版可先记录两种布局，再做 FLIP；拖拽匹配实际边界；沿路径移动把路径坐标转换进相同容器。

在拖动中改变窗口或滚动容器，核对命中点和目标。组件释放时清理拖拽实例与插件创建的监听。

配套资料按需用 `skill_read` 的 `resource` 参数读取：
