# 统一数值空间

先定义输入与输出的单位与方向，把鼠标、进度或滑块值映射到明确范围。clamp 用于硬边界，wrap 用于循环，snap 在离散选择时应用。

将映射器和插值器在事件外创建。核对两端、中点和反向输入，保证屏幕位置和展示的数值来自同一映射。
