# 滚动由一个所有者驱动

确认实际滚动容器、触发元素和起止位置。将进度映射到一条时间线，避免同一属性又被滚动监听和补间分别更新。

图片或字体加载导致尺寸变化后刷新测量。窄屏和减少动效时保留原内容阅读顺序；返回该页时检查滚动位置与动效一致。

配套资料按需用 `skill_read` 的 `resource` 参数读取：

- [upstream](references/upstream.md)
