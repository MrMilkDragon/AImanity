# 审查成品界面

捕获一个任务的起始、编辑和完成状态。先遮住所有描述文字，判断用户能否从结构和动词认出主要操作。把最妨碍操作的两处改在共用组件。

用一条直线对齐标题、字段、首列与工具条边缘。比对相邻控件字重、行距和内边距。检查图标在真实点击区域内的光学居中。

回到原先窗口尺寸，比较同一状态。分别记录影响操作的缺陷和仅属风格选择的变化。
