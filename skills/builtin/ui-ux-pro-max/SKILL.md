# 从任务设计界面

列出当前屏最重要的动作、完成后的可见结果和失败后可恢复的位置。按读写顺序排界面，把标签与输入框、标题与所属内容放在同一组。

先建立列、控件高度、字阶和间距的公共值，再排一屏真实数据。抽一个密集表单和一个内容页检验，确认同一元素没有两个高度。截断数值时保留单位，给长标签留换行或弹性宽度。

分别用键盘、小窗口、大字号和触屏完成该动作。记录挡住提交、读不清文本、焦点顺序错误的具体控件。颜色之外再给状态一个可感知的线索。
