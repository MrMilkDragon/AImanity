# 验收真实网页流程

在用户工程已有的浏览器测试环境打开真实入口，按可访问名称和角色定位输入与操作。等待目标状态出现，记录提交前后的可见结果。

读一次窄屏和键盘路径。异步列表以稳定 ID 或角色定位；打开新窗口时在触发动作前监听该窗口。

把失败时的 URL、可见状态、动作和截图归到同一次尝试。若当前工作是操作用户设备上的网页，使用产品的对应设备工具。
