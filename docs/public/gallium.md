# Gallium 0.0.7

[简体中文](#简体中文) · [Downloads](https://github.com/MrMilkDragon/AImanity/releases/latest)

Open the DMG on an Apple Silicon Mac and drag AImanity into Applications. The installer includes both guest runtimes and the Copilot speech model. Choose a language, then add a model in Settings. Use Devices to create an Android or Linux guest whenever you need one. The device canvas follows setup through boot. Select a failed device to see its error and retry, or ask the Agent to repair it in place.

Open Task & Goal next to the composer to add a Plan. Describe what should happen and when. Review the task and trigger, then save it. A Plan can run on a local schedule or match an app, title or text in a device notification.

Copilot transcribes locally and uses the Mac's voice for playback. Give AImanity microphone access when you start it. Drag an image into the conversation to share it with your model. The activity row opens to show reported actions and tool results.

Install Gallium from its DMG when coming from Fluorine. To uninstall, open Settings → Uninstall. This removes the app and its workspace, including virtual devices and conversations.

## 简体中文

[下载](https://github.com/MrMilkDragon/AImanity/releases/latest)

在 Apple Silicon Mac 打开 DMG，将 AImanity 拖入「应用程序」。离线安装包内置两类虚拟设备运行环境和 Copilot 语音模型。选好语言后，在设置中添加模型。可随时在设备管理中创建 Android 或 Linux。画布上会显示创建进度。启动失败时可打开设备错误重试，也可以让 Agent 原地修复。

在输入区打开「任务与目标」，输入你想在何时执行什么操作。确认整理后的任务和触发条件，再保存计划。计划可以按本地时间启动，也可以按设备通知的应用、标题或文字匹配。

Copilot 在本机转写，使用 macOS 系统音色播报。开启时授权麦克风即可。可将图片直接拖到对话框，展开活动行查看执行动作和工具回执。

从 Fluorine 换到 Gallium 请使用 DMG。需要移除应用和本机工作区时，使用「设置 → 卸载」，其中包含虚拟设备和对话。
