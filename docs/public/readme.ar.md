# AImanity

[English](../../README.md) · [جميع اللغات](../../README.md) · Apache-2.0

## التنزيل والحالة

[macOS 0.0.5 Europium (DMG)](https://github.com/MrMilkDragon/AImanity/releases/download/v0.0.5/AImanity-0.0.5-macos-arm64.dmg) · [Windows 0.0.5 Europium (EXE)](https://github.com/MrMilkDragon/AImanity/releases/download/v0.0.5/AImanity-0.0.5-windows-x64-setup.exe)

يتطلب macOS 15.0 أو أحدث ومعالج Apple Silicon. يتطلب Windows الإصدار 11 بمعمارية x64. يضم كل مثبّت Android وLinux والمحاكي والخدمات المحلية.

## الوظائف والسيناريوهات

يجمع AImanity بين هاتف Android وسطح مكتب Linux في محادثة واحدة مع وكيل نشط واحد. احفظ ملفات تعريف النماذج واختر الملف النشط من الإعدادات.

- تشغيل التطبيقات مثل WeChat: مراقبة الشاشة والإشعارات والرد وفق تعليمات المستخدم. تبقى قيود الحساب والتطبيق نافذة.
- العمل بين الأجهزة: استلام ملف في الهاتف ونقله إلى Linux ومعالجة جدول والتحقق منه وإرجاعه. اكتمال النقل وتسليم الملف إلى جهة اتصال نتيجتان منفصلتان.
- المهام المستمرة: إضافة تعليمات ومقاطعة التوليد مع حفظ الرسائل وسجل الإجراءات. يمكن للإشعارات تنشيط الوكيل، ويعمل Liberty عبر الجهازين.
- المهارات ومستندات المعرفة المرتبطة وملفات العمل مشتركة. النماذج وAPI والذاكرة والاتصالات الخارجية خاصة بالوكيل. تتصل الأجهزة مباشرة افتراضيًا. يمكنك ضبط وكيل الشبكة من مساحة العمل.

ترتبط الإجراءات بملاحظات الشاشة والجهاز والمهمة ودورة التحكم ومعرّف فريد. تُفحص النتائج المجهولة قبل إعادة التنفيذ.

## التقنية والبيانات

`apps/native`: ‏Rust (Iced/wgpu). ‏`crates`: ‏Rust وAxum وTokio. ‏`packages/protocol`: ‏protobuf. يحفظ PostgreSQL البيانات باستخدام SQLx. يتولى Cargo بناء المشروع.

المصدر منفصل عن بيانات المستخدم. لا تُنشر أقراص الأجهزة أو الحسابات أو المحادثات أو المرفقات أو المفاتيح. تحتاج التحديثات حزمًا ذات إصدارات ونسخًا احتياطية وترحيلًا وتراجعًا؛ ليس `git pull` فوق بيانات المستخدم آلية تحديث مناسبة.

## الاتجاهات والقيود والترخيص

تشمل خطط التطوير توسيع خيارات خدمات الصوت وإضافة مهارات للتطبيقات ومهام مكتبية تبدأ عند وصول إشعار.

تدعم الواجهة والإعداد الأولي عشر لغات. مفتاح اللغة يسار المهارات يبدّل الواجهة مع اتجاه RTL للعربية؛ لا يغيّر لغة أنظمة الأجهزة أو يترجم مخرجات الأدوات تلقائيًا.

المستخدم مسؤول عن الأذونات والحسابات والأفعال الخارجية وشروط التطبيقات. لا تستخدم النظام للاحتيال أو انتحال الهوية أو التصرف دون موافقة. المصدر الأصلي مرخّص Apache-2.0، وتحتفظ التبعيات بتراخيصها.
