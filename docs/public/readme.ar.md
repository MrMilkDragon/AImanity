# AImanity 0.0.6 Fluorine

[English](../../README.md) · [جميع اللغات](../../README.md) · Apache-2.0

## التنزيل والحالة

[تنزيل 0.0.6 Fluorine](https://github.com/MrMilkDragon/AImanity/releases/tag/v0.0.6) · [نتائج التثبيت والأجهزة التي خضعت للاختبار](release-status.md)

ثبّت الإصدار 0.0.6 تثبيتًا جديدًا. تفتح مساحة العمل للمرة الأولى بلا أجهزة. يمكنك إنشاء أجهزة Android أو Linux افتراضية حسب الحاجة، أو إقران جهاز بعيد، أو منح مهمة واحدة إذن الوصول إلى سطح مكتب المضيف.

## الوظائف والسيناريوهات

يختار الوكيل الجهاز المناسب للمهمة من الأجهزة المصرّح بها. تشترك الأجهزة في المحادثة وقائمة المهام وملفات العمل. ويمكن لوكلاء فرعيين إنجاز مهام مستقلة بالتوازي.

يتيح Copilot تعديل التعليمات بالصوت. يستكشف Liberty الأجهزة بحرية، ويعمل Task & Goal لتحقيق هدف تحدده.

## التقنية والبيانات

تستخدم الواجهة الأصلية Rust وIced وwgpu، وتستخدم الرسائل protobuf. تحفظ قاعدة البيانات المضمّنة redb الأجهزة والمحادثات والمهام محليًا.

## الاتجاهات والقيود والترخيص

تشمل خطط التطوير توسيع خيارات خدمات الصوت وإضافة مهارات للتطبيقات ومهام مكتبية تبدأ عند وصول إشعار.

تدعم الواجهة والإعداد الأولي عشر لغات. مفتاح اللغة يسار المهارات يبدّل الواجهة مع اتجاه RTL للعربية؛ لا يغيّر لغة أنظمة الأجهزة أو يترجم مخرجات الأدوات تلقائيًا.

المستخدم مسؤول عن الأذونات والحسابات والأفعال الخارجية وشروط التطبيقات. لا تستخدم النظام للاحتيال أو انتحال الهوية أو التصرف دون موافقة. المصدر الأصلي مرخّص Apache-2.0، وتحتفظ التبعيات بتراخيصها.
