## 다운로드와 현황

[0.0.6 Fluorine 다운로드](https://github.com/MrMilkDragon/AImanity/releases/tag/v0.0.6) · [설치 검증 및 실기기 확인 현황](release-status.md)

0.0.6은 새로 설치합니다. 처음에는 연결된 기기 없이 작업 공간이 열립니다. 필요할 때 Android 또는 Linux 게스트를 만들거나 원격 기기를 페어링할 수 있습니다. 호스트 데스크톱 접근 권한은 작업별로 부여합니다.

## 기능과 사용 시나리오

에이전트는 허용된 기기 중에서 작업에 맞는 기기를 고릅니다. 모든 기기가 대화, 할 일, 작업 파일을 공유합니다. 독립된 작업은 하위 에이전트가 동시에 처리할 수 있습니다.

Copilot에서는 음성으로 지시를 수정할 수 있습니다. Liberty는 자유롭게 탐색하고 Task & Goal은 지정한 목표를 수행합니다.

## 기술과 데이터

네이티브 UI는 Rust, Iced, wgpu를 사용하고 통신 규약에는 protobuf를 사용합니다. 기기, 대화, 작업은 내장 redb에 저장됩니다.

## 향후 방향·책임·라이선스

앞으로 음성 서비스 선택지를 늘리고 앱별 스킬과 알림을 받아 시작하는 사무 작업을 확장할 예정입니다.

인터페이스와 초기 설정은 10개 언어를 지원합니다. Skill 왼쪽의 언어 버튼으로 전환하며 게스트 OS와 도구 원문은 자동 번역하지 않습니다. 아랍어는 오른쪽에서 왼쪽으로 표시됩니다.

사용자는 권한, 계정, 외부 작업과 앱 약관에 책임을 집니다. 사기, 기만 또는 동의 없는 작업에 사용하지 마세요. 자체 코드는 Apache-2.0이며 타사 구성 요소는 각 라이선스를 따릅니다.
