## ダウンロードと現状

[0.0.6 Fluorine をダウンロード](https://github.com/MrMilkDragon/AImanity/releases/tag/v0.0.6) · [インストール検証と実機の確認状況](release-status.md)

0.0.6 は新規インストールします。初回はデバイスがない状態で起動します。必要に応じて Android や Linux のゲストを作成し、リモート端末をペアリングできます。ホストのデスクトップはタスクごとにアクセスを許可します。

## 機能と利用例

エージェントは許可された端末から作業先を選びます。会話、タスク一覧、作業ファイルは全端末で共通です。独立した作業はサブエージェントが並行して進められます。

Copilot では音声で指示を修正できます。Liberty は自由に探索し、Task & Goal は指定した目標に沿って作業します。

## 技術とデータ

ネイティブ UI は Rust、Iced、wgpu を使用し、通信には protobuf を使います。デバイス、会話、タスクは組み込みの redb に保存されます。
