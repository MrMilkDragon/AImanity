# Open a Fluorine workspace

[简体中文](getting-started.zh-CN.md)

Fluorine 0.0.6 is in development. It starts with a fresh profile. For an installed 0.0.5 client, use the [Europium guide](https://github.com/MrMilkDragon/AImanity/blob/v0.0.5/docs/public/getting-started.en.md).

1. Launch the new client, select your language and enter the workspace.
2. Open Agent settings, enter the provider, protocol, endpoint, model name and any required key. Test the connection and save.
3. Send a message in the shared conversation. You can use the workspace with zero devices.
4. Import a working file or create a knowledge document. Reopen the client to return to the same conversation and files.
