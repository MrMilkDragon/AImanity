# AImanity 0.0.6 Fluorine

[English](../../README.md) · [Все языки](../../README.md) · Apache-2.0

## Загрузка и статус

[Скачать 0.0.6 Fluorine](https://github.com/MrMilkDragon/AImanity/releases/tag/v0.0.6) · [Проверка установки и испытания на устройствах](release-status.md)

Установите версию 0.0.6 заново. При первом запуске рабочее пространство пустое. Можно создать гостевую систему Android или Linux, подключить удалённое устройство или дать доступ к рабочему столу хоста для одной задачи.

## Возможности и сценарии

Агент выбирает устройство из числа разрешённых. У устройств общие диалог, список задач и рабочие файлы. Независимые задачи могут параллельно выполнять субагенты.

В Copilot можно уточнять указания голосом. В режиме Liberty агент исследует устройства самостоятельно. В Task & Goal он работает над заданной целью.

## Архитектура и данные

Интерфейс написан на Rust с Iced и wgpu. Для сообщений используется protobuf. Встроенная база redb хранит устройства, диалоги и задачи локально.

## Развитие, ограничения и лицензия

В планах — больше голосовых сервисов, навыков для приложений и рабочих задач, которые запускаются по уведомлению.

Интерфейс и первичная настройка поддерживают десять языков. Переключатель слева от Skills меняет интерфейс; язык гостевых ОС и исходные тексты инструментов автоматически не переводятся.
