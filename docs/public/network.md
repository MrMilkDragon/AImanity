# Workspace proxy

## Fluorine 0.0.6

Open **Workbench proxy**, enter a Clash-compatible YAML subscription URL and select **Import**. Select a node and enable the proxy to route the workspace's default model connection. **Refresh** reloads the subscription. Set a proxy on a model profile to give that model its own route.

The client keeps the subscription in the local workspace. Device pairing uses its own SSH connection. Hosts and paired computers keep their system network settings.

[Connect a local or remote desktop](native-client.en.md) · [Europium 0.0.5 network setup](https://github.com/MrMilkDragon/AImanity/blob/v0.0.5/docs/public/network.md)

## 中文

在「工作台代理」填入 Clash 兼容的 YAML 订阅地址，点击「导入」。选择节点并启用后，工作区默认通过该节点连接模型。「刷新」会重新读取订阅。需要为某个模型单独选路时，可在其配置中填写代理地址。

订阅保存在本地工作区。配对设备经独立 SSH 连接，宿主机和远程电脑沿用各自的系统网络设置。
