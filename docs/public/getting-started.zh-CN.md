# 打开 Fluorine 工作区

[English](getting-started.en.md)

0.0.6 Fluorine 正在开发，首次安装使用全新配置。已安装 0.0.5 的用户可查阅 [Europium 指南](https://github.com/MrMilkDragon/AImanity/blob/v0.0.5/docs/public/getting-started.zh-CN.md)。

1. 打开新客户端，选择语言，进入工作台。
2. 在 Agent 设置中选择服务商和协议，填写服务地址、模型名及所需密钥。测试连接后保存。
3. 在共享对话中发送消息。零台设备也可以开始对话。
4. 导入工作文件或创建知识文档。重开客户端可继续查看原会话和文件。
